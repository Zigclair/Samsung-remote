# Samsung Frame Remote

Android remote for Samsung Frame TVs over local Wi-Fi.

Build using the GitHub Actions **Build Android APK** workflow. Download the `FrameRemote-debug-apk` artifact from the Actions run and install the APK on Android.

The phone and TV must be on the same network. Enter the TV IP address and approve pairing on the TV. This is an experimental build; Art Mode, app shortcuts and power-on depend on TV model. No PC or Raspberry Pi bridge is required.
